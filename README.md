# The Hepburn tracker

The page: https://jonathanmable.github.io/hepburn-hub/

Availability and asking-price history for studios and one-bedrooms at The Hepburn (2400 16th St NW, Washington DC),
with a comparison of the building's floor plans.

`index.html` is generated. A scraper checks the building's availability page three times a day; after each check a
build turns the scan data into this page and pushes it here. Nothing in this repository is edited by hand.

Not affiliated with The Hepburn. Prices are the building's published asking prices.
