How it works

44 days of scans so far, since Aug 25.

  • Three checks a day. A scraper reads the building's availability page at midnight, 8 am and 4 pm Eastern and records one row per listed unit.
  • Two places, one winner. Each check runs on GitHub Actions and on a laptop. Whichever gets there first records it; the other sees the check is covered and skips.
  • Email on change. When a unit is newly listed, or stops being listed, an email goes out in the same run that rebuilds this page.
  • Every number is computed. This page is generated from the scan data after each check. If a build fails its tests or its privacy check, the previous page stays up.
  • What it costs. Nothing. It runs on free GitHub Actions minutes and uses no paid services.
  • Who built it. One person set the goals and made the calls. AI agents (Claude Code) built and run it: one decides what is tracked, another owns the code, tests and schedule.
Not affiliated with The Hepburn. Prices are the building's published asking prices and can change at any time.
